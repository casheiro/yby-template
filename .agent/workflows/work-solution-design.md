# Workflow: Work Solution Design

**Objetivo:** Planejar a implementação detalhada.

## Quando usar
- Após `work-discovery`.
- Antes de escrever código de produção.

## Passos

1. **Brainstorming**
   - Gere opções de implementação.
   - Consulte a Persona Arquiteto se necessário.

2. **Plano de Implementação**
   - Crie/Atualize `implementation_plan.md`.
   - Liste arquivos a criar/modificar.
   - Defina estratégia de testes.

3. **Revisão de UKIs**
   - A solução proposta viola alguma UKI?
   - A solução exige criar uma nova UKI? (Se sim, planeje `uki-capture`).

4. **Aprovação**
   - Apresente o plano ao usuário.
   - Só avance para implementação após "De acordo".
