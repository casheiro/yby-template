# Workflow: Synapstor

**Objetivo:** Criar ou atualizar a estrutura de governança semântica do repositório.

## Quando usar
- Inicialização do projeto (Bootstrap).
- Grandes refatorações de governança.

## Passos
1. **Alinhamento:** Entender o papel do repo.
2. **Síntese:** Mapear contexto, backlog e fluxos.
3. **Personas:** Definir quem atua no projeto.
4. **Materialização:** Criar/Atualizar `.synapstor/` e `.agent/`.

*Nota: Este workflow é auto-gerenciado pelo próprio Synapstor.*
